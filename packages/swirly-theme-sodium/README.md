# @swirly/theme-sodium

[![npm](https://img.shields.io/npm/v/@swirly/theme-sodium.svg)](https://www.npmjs.com/package/@swirly/theme-sodium) [![JavaScript Standard Style](https://img.shields.io/badge/code%20style-standard-brightgreen.svg)](https://standardjs.com)

Theme for [Swirly](https://github.com/timdp/swirly) matching the line art of the
Sodium FRP book figures: black on white, no fills, everything italic, and grid
columns sized to what they hold.
